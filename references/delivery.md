# 交付与 QA

交付静态图，不输出剪辑视频。保留完整分辨率原图；预览是附加文件。每张图均可回到其 source、原文、时间码与上下文，不以一条泛泛的来源链接代替逐句记录。

1. **语义**：回听/回看选段和上下文；核对译文、讲者、限定词、删节。清单的 `reviewed: true` 不能代替实际审核。
2. **时间**：检查至少两个锚点，并实际看每张提取帧；官方字幕与媒体时钟分别呈现，不能混称。
3. **图像**：打开每张原尺寸图和手机预览，检查切脸、失真、错人物、字幕切换、缺字、字框溢出、原生字幕两端、标题与译文标識。禁止只根据脚本退出码宣布视觉通过。
4. **文件**：核对数量、尺寸、RGB、解码与版本。PNG/JPEG 都保留原分辨率；客户端灰屏时可附单张 720×960 PNG，记录故障而非臆测原因。
5. **出处**：附人类可读来源表及 `provenance.json`。每句列 speaker、source URL、original、translation、start/end、offset、context、excerpt note。必要的媒体使用条件一并说明。
6. **范围**：明确哪些做完，哪些依赖宿主尚未完成。没有语义验证、FFmpeg 或真实视频时，不把合成演示的通过写成完整真实流程已通过。

发布前对分发包执行隐私/权利检查：不打包真实第三方视频或截图、账号数据、对话 ID、签名 URL、凭据、本机工作路径、平台传输代码或私有笔记。自写几何 fixture 要显著标示为演示，禁止署给真实人物。

本地成果可以通过宿主当前的文件交付机制保存；不要把某个平台的私有 API 写成技能硬依赖。保存失败时保留本地成品，报告准确结果，不声称已送达。发布、推送、创建远端仓库或全局安装均须另外授权。
