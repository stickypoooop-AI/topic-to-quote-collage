# 操作手册：根据输入决定下一步

本技能交付静态拼图及出处，不剪视频。宿主 Agent 负责理解主题、搜索、听看、翻译与判断；包内脚本只对已取得的本地媒体和已审清单执行校验、取帧及排版。

## 四个判断，比八套流程更有用

| 判断 | 已明确 | 未明确 |
|---|---|---|
| 来源 | 核对原发布者、版本、语言与权限；检查本地媒体 | 用宿主搜索追溯原始视频；只有文字时先交付检索/核验结果 |
| 片段 | 回看时间点与上下文，核验准确性 | 通读或听看完整相关段落，选连贯候选，不只全文搜关键词 |
| 编辑角度 | 沿用确认或精确 brief，不重复问 | 先讨论并明确确认；主题型请求在此之前不开始来源搜索 |
| 范围 | 按用户要求制作或局部改动 | 只问影响结果的缺项；数量、尺寸可说明默认值后推进 |

“明确确认”可以是用户对所提切口的接受，也可以是当前请求已明确规定要表达的角度与片段。仅说“做点金句图”不算。来源不支撑已确认角度时，应呈现反例或缺口，再讨论调整，不把问题藏在措辞里。

## 常见输入与可复制请求

| 用户提供 | 确认什么 | Agent 执行 | 交付与停止条件 |
|---|---|---|---|
| 视频 + 精确时间或原话 | 已有角度/范围直接沿用；只补真正缺项 | 看前后段、核对原话与说话人；校时；选稳定帧；译文审核；排版 | 拼图、原文与双时钟；时间或台词不符时说明差异 |
| 视频，未选片段 | 讨论希望传达的问题与受众，确认角度 | 阅读文字稿并回看相关段落，选择少量完整论点；不能按关键词机械截句 | 连贯组图与出处；无合适内容则回到讨论 |
| 只有主题 | **搜索前**确认清晰切口 | 再搜索多语原始长视频，比较候选与反证，筛选真实引语 | 支撑该切口的图和核验记录；证据薄弱时交代未采用原因 |
| 台词或截图，需追溯 | 是找出处、核验还是重新制图 | 将文字/OCR 当线索，寻找原始记录并核对版本、语境、人物 | 可证实的出处或未解决清单；追溯失败不生成“真人视频截图” |
| 文字稿/字幕，无视频 | 文稿有无来源、时间轴，是否只做候选筛选 | 先核对文字来源，列候选并取得对应视频；ASR 先复听 | 可先交候选清单；没有视频不得悄悄用合成人物补图 |
| 指定讲者或节目 | 还需明确讨论的问题，人物不是角度 | 搜索原节目/完整访谈，核查来宾、主持人和转述关系 | 精确到每句的归属；不能把主持人提问当嘉宾结论 |
| 多段视频 | 确认共同问题与各图作用 | 分来源独立校时，寻找互补论点，保留观点差异 | 一致视觉的一组图；每张独立来源，不能拼出原来不存在的连续发言 |
| 已有拼图修订 | 明确改翻译/帧/布局/尺寸中的哪些 | 复用原清单；译文改动复核原文，帧改动重提取，布局重看裁切，改尺寸重排 | 新版和更新出处；默认新目录，只有明确替换才覆盖 |

复制以下任一请求，再替换方括号内容：

1. `用 $topic-to-quote-collage 处理 [视频] 的 [时间段]。角度是 [问题]，中文翻译字幕，交付拼图和来源记录。`
2. `用 $topic-to-quote-collage 从 [视频] 选合适片段。我关注 [困惑]，先帮我确认切入角度。`
3. `用 $topic-to-quote-collage 做 [主题]。先讨论一个明确角度，我确认后再搜索多语言原始视频。`
4. `用 $topic-to-quote-collage 追溯这句 [台词/截图] 的原始视频。先核验，不确定时保留不确定性。`
5. `用 $topic-to-quote-collage 读这份 [字幕/文字稿]，围绕已确认的 [角度] 选句。找到对应视频后才做真实帧拼图。`
6. `用 $topic-to-quote-collage 从 [讲者/节目] 的完整访谈中找 [问题] 的相关表达，先和我确认角度。`
7. `用 $topic-to-quote-collage 把这几段 [视频] 做成围绕 [已确认角度] 的一组图，各图分别给出一个互补观点。`
8. `用 $topic-to-quote-collage 修改 [旧图及清单]：只改 [翻译/帧/版式/尺寸]，其他已确认内容沿用，另存新版。`

## 遇到这些情况怎样继续

| 情况 | 可继续的工作 | 停止或回退点 |
|---|---|---|
| 视频无字幕 | 已有转录工具或人工听录，标出不清处，逐句复听 | 没有可复核的原话就不渲染引语 |
| 外语来源 | 保存原文、时间轴与中文；审核否定、数字、语气及专有名词 | 无法准确理解关键句时换来源或说明不足 |
| 多人对话 | 每句指定说话人，保留问答和转述关系 | 身份不清、剪切接话容易误导时不用该片段 |
| 链接打不开 | 尝试公开原发布页或合法替代版本，保留失败说明 | 不登录、不用 cookies、不绕限制；请求可访问副本或换来源 |
| 相关引语不够 | 说明搜到的内容能支持什么，列出缺口 | 回到选题讨论；不编造、不硬凑图数 |
| 官方字幕与本地视频相差片头 | 用前后两个可辨识音画锚点测偏移，检查中间片段 | 偏差不恒定就分来源片段，不继续用单一偏移 |
| HLS/片段截取 | 检查实际首帧与语音，不假设下载请求起点就是新时钟零点 | 截取断点/广告无法对应时重新取更完整的媒体 |
| 中文太长 | 在不改义的前提下拆成语义连续的条或另一张图；更新节选说明 | 不自动截断、不把字号压到难以阅读、不删限定词 |
| 原生字幕被裁 | 扩大真实裁切区域，完整保留两端，统一缩放 | 仍无法可读则换帧或讨论改为标明翻译的脚本模式 |
| 原图在聊天中灰屏 | 检查文件能否本地解码；附单张 RGB PNG 预览 | 保留原分辨率原件；只报告实际交付故障，不泛化格式故障 |

## 一次正常执行会留下什么

编辑角度确认 → 来源候选与淘汰理由 → 复核过的原文及译文 → 两个以上校时锚点 → manifest → 真实帧及提取记录 → 成品与 provenance → 实际像素 QA。可合并相邻步骤，不要求用户逐步批准。只有角度未定、证据不足或必须改变明确要求时回到讨论。

只有旧图、没有 manifest 时：纯尺寸/留边修改可使用宿主现有图像工具，并保留原有出处的不确定状态；本包渲染脚本仍需要清单和原始帧。修改引语、翻译或新增真实帧则必须先取得可核查来源，不能从旧图反推出并未确认的原话。
